# Klinik Veri Analizi

Bu proje, anonimleştirilmiş klinik veriler üzerinden uçtan uca veri analizi ve biyostatistiksel değerlendirme sürecini göstermektedir.

## Projenin Amacı

Klinik veri setlerinin temizlenmesi, düzenlenmesi, istatistiksel olarak analiz edilmesi ve elde edilen sonuçların anlaşılır biçimde raporlanması amaçlanmıştır.

## Çalışma Kapsamı

- Klinik verilerin düzenlenmesi
- Veri temizleme ve kontrol
- Tanımlayıcı istatistikler
- Grup karşılaştırmaları
- Biyostatistiksel analizler
- Sonuçların raporlanması
- Python ile analiz sürecinin otomasyonu

## Kullanılan Araçlar

- Python
- Pandas
- NumPy
- SciPy
- Excel

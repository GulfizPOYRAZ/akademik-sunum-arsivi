# Bionluk Çalışmaları

Bu klasör, Bionluk platformunda gerçekleştirilecek profil ve hizmet çalışmalarını takip etmek amacıyla oluşturulmuştur.

## Durum

Henüz Bionluk üzerinden bir çalışma mevcut değil.

İlerleyen süreçte hazırlanacak hizmet ilanları ve tamamlanan işler bu klasörde düzenlenecektir.

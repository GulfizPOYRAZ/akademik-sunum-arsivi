# Klinik Veri Analizi

Bu proje, anonimleştirilmiş klinik veriler üzerinde uçtan uca veri analizi ve biyostatistiksel değerlendirme sürecini göstermektedir.

## Projenin Amacı

Çalışmanın amacı, çok sayfalı ve farklı yapıda bulunan klinik verilerin temizlenmesi, standartlaştırılması, istatistiksel olarak analiz edilmesi ve sonuçların raporlanmasıdır.

Analiz sürecinde kişisel kimlik bilgileri kaldırılmış ve çalışma portföy sunumuna uygun anonim bir yapıda hazırlanmıştır.

## Kullanılan Teknolojiler

- Python
- Pandas
- NumPy
- SciPy
- OpenPyXL
- Python-docx
- Microsoft Excel
- Microsoft Word

## Uygulanan Analizler

Projede:

- Veri temizleme ve standartlaştırma
- Eksik veri kontrolü
- Tanımlayıcı istatistikler
- Mann–Whitney U testi
- Fisher’s Exact Test
- Spearman korelasyon analizi
- Çok sayfalı Excel raporlama
- Otomatik Word raporu oluşturma

işlemleri gerçekleştirilmiştir.

## Veri Güvenliği

Çalışma portföy amacıyla anonimleştirilmiştir.

Hasta adı ve diğer doğrudan kimlik bilgileri analiz akışından çıkarılmıştır. GitHub üzerinde kaynak hasta verileri paylaşılmamaktadır.

# Upwork Çalışmaları

Bu klasör, Upwork platformu üzerinden gerçekleştirilen çalışmaların ve tamamlanan projelerin arşivlenmesi amacıyla oluşturulmuştur.

Henüz tamamlanmış bir Upwork çalışması bulunmamaktadır.

İleride Upwork üzerinden gerçekleştirilen projeler, ilgili proje klasörleriyle birlikte burada paylaşılacaktır.

# Wellfound Çalışmaları

Bu klasör, Wellfound platformunda kariyer ve iş başvurusu süreçleri kapsamında gerçekleştirilen çalışmaları takip etmek amacıyla oluşturulmuştur.

## Yapılan Çalışmalar

- Wellfound profilinin incelenmesi
- Profil bilgilerinin gözden geçirilmesi
- Veri analizi ve analitik odaklı iş fırsatlarının değerlendirilmesi

## Durum

Uygun iş ilanları takip edilmektedir.

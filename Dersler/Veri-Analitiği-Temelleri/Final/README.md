# Final

Bu bölüm, Veri Analitiği Temelleri dersi final çalışmasını içermektedir.

## Final Konusu

QuickMart satış verileri üzerinden hazırlanmış bir vaka çalışmasıdır.

Çalışmada aşağıdaki başlıklar ele alınmıştır:

- Özellik mühendisliği
- Model incelemesi
- Alternatif model önerileri
- Yönetici iletişimi
- Etik değerlendirme
- Tekrarlanabilirlik
- Stratejik bakış açısı

Final çalışmasının ayrıntıları `QuickMart-Vaka-Calismasi` klasöründe yer almaktadır.

# n8n AI Agent Çalışmaları

Bu klasör, Yapay Zeka ve Teknolojileri dersi kapsamında n8n üzerinde gerçekleştirilen AI Agent ve otomasyon denemelerini içermektedir.

## Çalışmalar

### n8n AI Agent İlk Çalışma

Temel AI Agent yapısının kurulması amacıyla hazırlanmıştır.

Çalışmada:

- Chat Trigger
- Google Gemini Chat Model
- Simple Memory
- AI Agent
- HTTP Request

bileşenleri kullanılmıştır.

### Google Calendar Randevu Denemesi

AI Agent ile Google Calendar entegrasyonunun denenmesi amacıyla hazırlanmıştır.

Çalışmada:

- Randevu uygunluk kontrolü
- Google Calendar üzerinden etkinlik oluşturma
- Google Gemini
- Simple Memory
- AI Agent

bileşenleri kullanılmıştır.

### AI Randevu Yönetim Sistemi

Önceki denemelerin geliştirilmiş sürümüdür.

Sistem; kullanıcıdan randevu bilgilerini almak, takvim uygunluğunu kontrol etmek ve Google Calendar üzerinde randevu işlemlerini yönetmek amacıyla geliştirilmiştir.

Çalışmada:

- n8n AI Agent
- Google Gemini
- Google Calendar
- Webhook
- Simple Memory
- Randevu oluşturma
- Randevu uygunluk kontrolü
- Randevu iptal işlemleri

uygulanmıştır.

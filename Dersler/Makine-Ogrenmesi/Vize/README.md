# Vize

Bu bölüm, Makine Öğrenmesi dersi kapsamında hazırlanan vize çalışmasını içermektedir.

## Vize Konusu

Makine Öğrenmesi Yöntemleri ile Eğitim Başarısının Tahmini Modeli başlıklı makalenin incelenmesi.

## Çalışma Kapsamı

- Araştırmanın amacı
- Veri setinin yapısı
- Kullanılan makine öğrenmesi yöntemleri
- Veri ön işleme adımları
- Eğitim ve test verisinin ayrılması
- Model performanslarının karşılaştırılması
- Bulguların ve sonuçların değerlendirilmesi

Vize çalışmasının ayrıntıları `Makale-Incelemesi` klasöründe yer almaktadır.

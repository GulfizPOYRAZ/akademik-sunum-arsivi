# Amazon Duygu Analizi

Bu çalışma, Web ve Metin Analitiği dersi kapsamında yapılan uygulama ve deneme çalışmalarından biridir.

## Çalışmanın Konusu

Amazon uygulama yorumlarından oluşan veri seti üzerinde duygu analizi ve metin sınıflandırma uygulamaları gerçekleştirilmiştir.

Yorumların pozitif, negatif ve nötr olarak sınıflandırılması amaçlanmış; doğal dil işleme ve makine öğrenmesi yöntemleri birlikte kullanılmıştır.

## Uygulanan Yöntemler

- NLTK ile metin işleme
- VADER ile duygu skoru hesaplama
- Cümle tokenization
- Metin temizleme
- Stopword kaldırma
- Lemmatization
- TF-IDF vektörleştirme
- Logistic Regression
- Linear SVC
- Random Forest
- Multinomial Naive Bayes
- Confusion Matrix
- Precision, Recall ve F1-Score değerlendirmeleri
- Kelime bulutu görselleştirmeleri

## Amaç

Farklı makine öğrenmesi modellerinin duygu sınıflandırma performanslarını karşılaştırmak ve pozitif, negatif ve nötr yorumların hangi ölçüde doğru sınıflandırılabildiğini incelemektir.

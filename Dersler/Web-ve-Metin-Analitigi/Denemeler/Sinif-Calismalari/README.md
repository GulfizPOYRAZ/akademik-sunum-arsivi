# Sınıf Çalışmaları

Bu klasör, Web ve Metin Analitiği dersi kapsamında yapılan sınıf içi uygulama ve deneme çalışmalarını içermektedir.

## Çalışma Kapsamı

Bu çalışmalar kapsamında temel metin ön işleme ve doğal dil işleme adımları uygulanmıştır.

Uygulamalarda özellikle şu konular ele alınmıştır:

- HTML etiketlerinin temizlenmesi
- URL temizleme
- Büyük/küçük harf dönüşümleri
- Özel karakterlerin kaldırılması
- Fazla boşlukların temizlenmesi
- Yazım hatalarının düzeltilmesi
- Kelime tokenization
- Cümle tokenization
- Stopword temizleme
- Stemming
- Lemmatization
- Bag of Words (BoW)
- spaCy ve NLTK uygulamaları
- SMS verileri üzerinde spam ve normal mesaj örneklerinin incelenmesi
- Farklı örnek metinler üzerinde metin analizi uygulamaları
